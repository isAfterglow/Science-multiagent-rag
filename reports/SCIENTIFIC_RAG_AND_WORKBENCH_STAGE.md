# 科研 RAG 与工作台阶段交付

## 阶段一：可追溯科学语料与检索策略

科学语料扩展为 8 份公开 NASA NTRS 资料：TUFROC、Advanced TUFROC、TPS 材料热试验、炭化烧蚀、硅酸盐烧蚀、烧蚀热防护基础、FIATC 热响应化学程序和多层壁扫描专利。共解析 186 个页级文档；6 页使用有界 OCR 回退。每个来源保存访问标记、URL、SHA-256、来源等级、主题和中英文术语 Profile。

OCR 已从“低文本页无限回退”改为“每份资料有页面预算”。超出预算的原始页面仍保留在 PDF 中，避免历史扫描件拖慢整批入库。

44 题评测（项目资料、公开论文、扫描/OCR、页码、跨来源和等级边界）显示，Profile 仅用于来源级重排、原文保留用于页级定位的两级检索，显著优于把标签重复写入每页正文。

| 方案 | Source Recall@5 | 科学资料 Recall@5 | 页码命中 | OCR 页码命中 | P50 / P95 ms |
|---|---:|---:|---:|---:|---:|
| 初始 BM25 document | 72.73% | 66.67% | 75.76% | 75.00% | 0.172 / 0.298 |
| Profile + 来源配额 BM25 | 94.32% | 93.94% | 75.76% | 100.00% | 1.657 / 1.949 |
| Dense | 92.80% | 96.97% | 84.85% | 75.00% | 119.000 / 148.254 |
| Hybrid | 92.42% | 93.94% | 78.79% | 75.00% | 122.558 / 208.609 |
| Hybrid + Rerank | 94.70% | 96.97% | 72.73% | 50.00% | 3237.251 / 4009.941 |

因此默认运行时策略是：公开论文优先 Dense；扫描/OCR 资料改用 BM25；Hybrid+Rerank 仅保留为离线高精度实验选项。这个策略是测得的准确性、页定位和 CPU 延迟权衡，不是固定偏好。

## 阶段二：科学回答可靠性

新增确定性 Reviewer 策略：

1. 项目真实 case、指标、参数、运行状态或耗时，若没有 Registry 分析或 A/B 级项目证据，拒绝将 C/D 外部资料作为结论依据。
2. 精确数值、尺寸、厚度、温度或专利号请求命中 OCR 置信度低于 0.85 的扫描页时，要求人工核对原始页图。
3. 外部文献机理问答与高置信扫描结构问答不会被误拦截。

`eval/scientific_safety_eval.py` 的 8 条策略回归全部通过。策略不由 LLM 决定，LLM 无法降低来源等级要求。

## 阶段三：工作台

工作台增加：节点流转带、证据需求、来源等级徽标、资料标题、页码、OCR 置信度、原始扫描页链接、审核理由、知识缺口、计划审批、隔离预览、后台任务与资源队列。`/knowledge-pages` 仅暴露受控的已渲染知识页，不提供任意路径文件访问。

API 冒烟验证：`/health`、`/` 和扫描页 `/knowledge-pages/nasa_multiwall_1982_p001.png` 均返回 200。
